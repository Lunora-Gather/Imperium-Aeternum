# Imperium Aeternum 1.1.2

## 界面和开局

- 四套主题各自调整纸面纹样、边框、文字和按钮，统一处理浅底、深底和状态色的可读性。
- 手机大厅显示四套主题名称，主要按钮单独占一行。国政总览可在窄屏换行显示操作和结算状态。
- 从大厅可以直接继续已检查的本地存档，也可以下载私有云存档后继续指定槽位。存档检查在后台运行。

## 回合、云存档与多人

- 修正部分经济、外交和战争结算，年报使用实际结算结果。
- 世界规模模拟按单回合统计 P95，长局遇到阶段性终局后仍可在压力测试中继续执行。
- 多设备云存档按版本识别冲突。离线存档会在下次联网时重新核对，迟到的请求会按对应账号和本地版本处理。
- 共享世界恢复国家列表、年度准备和服务端回合。命令重试复用原请求标识，掉线恢复后可以继续核对已提交的操作。
- 私聊和版图频道支持中文输入法选词，发送失败可重试，切换账号时取消尚在读取的待发图片。

## 发布

GitHub Pages 的候选构建须通过发布检查和系统 Safari 测试。部署完成后，工作流校验每份线上文件。配套更新涉及共享世界、云存档和社交三个 Appwrite 云函数。仓库内的版图种子用于初始化新世界。
