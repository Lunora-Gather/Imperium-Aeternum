# Imperium Aeternum 1.2.0

「东亚风云」的五年边约现在会迎来第二次谈判。与同一邻国实际交货满两年，有机会免礼金续约五年。刺探对方或双方互信恶化时，使团可能只肯接受三年短约。玩家可以拒绝，接受时会看到期限和礼金，结果载入史册。

## 贸易与收成

- 在生成地图上，从「舆图 → 商路」查看实际起运地和目的地，再去经济页签约和开线。输入线带回口粮，输出线按实际交货量收款。
- 商业使命按顺序发奖，后两章分别需要一条、两条运营商路。禁运会暂停交付。
- 年报列出实际商路收益与开垦后的首次增产。经济页可查看产粮、居民口粮、军粮和预计库存变化。

## 开局与存档

- 「东方破晓」从田税改革开始。富裕且和平的单人国家还有机会接到三年供粮邀约，也可以选择修渠或保留粮款。
- 已有存档可继续使用。旧档中的海上首都会修复为沿岸据点，边约交货年数从新版实际交付起计算。
- 共享世界采用同一套贸易和粮食结算。共享指令等待确认期间，读档会提示先完成提交。
