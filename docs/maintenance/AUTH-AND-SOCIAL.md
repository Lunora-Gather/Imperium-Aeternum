# 账号验证与社交体验

> 本文是账号注册、登录反馈、好友入口和版图聊天体验的当前事实源。共享世界结算规则仍以 `SHARED-WORLD.md` 为准。

## 1. 可信账号流程

- 游客可以完整使用单机模式，不强迫登录。
- 新账号必须先填写昵称、邮箱和密码，再由 Appwrite Email OTP 发送 6 位验证码。
- 只有验证码建立已验证会话后，客户端才设置昵称与密码并完成注册。
- 未验证邮箱不能使用密码会话进入应用；可以通过邮箱验证码完成验证并登录。
- 忘记密码时可使用 6 位邮箱验证码建立临时已验证会话；账号网关只接受 10 分钟内新建、包含邮箱因子的 token 会话，并只更新同一用户的既有密码账号。成功后直接安全登录。
- 验证码由 Appwrite 生成和校验，前端不保存验证码、不建立自有验证码表。
- 邮箱只用于认证，不写入公开玩家资料；好友使用独立好友码。

### 状态机

`填写资料 → 发送验证码 → 验证邮箱 → 设置昵称/密码 → 已认证`

切换登录/注册模式或修改资料会清除本地待验证状态。验证码 15 分钟有效，界面限制 60 秒后重发，以降低误触和频繁请求。

## 2. 交互与视觉规则

- 所有主操作必须提供按下位移、键盘焦点、禁用态和异步加载反馈。
- 浏览器密码管理器自动填充必须继承主题背景、文字与焦点环，不得回退为浏览器默认白色或浅蓝色块。
- 表单在输入时显示就地校验；服务端结果使用 `role=status` 通知。
- 注册页明确显示两步进度与“邮箱验证是必需步骤”，不再提供直接创建并登录路径。
- 移动端保持单列字段、可滚动弹窗和至少 38px 的主要点击区域。

## 3. 玩家发现、名片与社交入口

- 菜单顶栏使用“社交”入口；游戏内左下角使用悬浮消息入口。它与右下角的新手引导分开，避免遮挡。
- 未读私信和待处理好友申请统一显示数字徽标；有新动态时悬浮入口改变描边并产生低频提示动画。
- “发现玩家”只列出当前 `world_memberships` 中的同图成员，并由 Social Gateway 先验证请求者也是该版图成员；不得扫描或枚举全站资料。
- 同图成员可一键发送好友申请，好友码作为折叠的备用添加方式保留；好友一旦接受即脱离版图生命周期，换图或离开版图后仍可继续私聊。
- 公开名片只包含昵称、称号、宣言、头像主题、好友码、加入时间和最近活动，不暴露邮箱。
- 玩家头像和昵称是统一的名片入口；本人可以编辑昵称、称号、宣言和头像主题。
- 好友申请由接收方直接“接受”或“拒绝”，不要求再次输入好友码。
- 版图频道入口位于世界规则与国家列表之间，不需要滚动到页面底部寻找。
- 聊天默认收起；新消息显示未读徽标，打开后标记为已读。
- 聊天区区分本人/他人气泡，显示当前执政国提示、字数、发送状态和键盘快捷键。
- 历史记录与 Realtime 事件必须按 Appwrite 行 ID 合并去重、按创建时间稳定排序并截取最近 50 条；历史请求不得覆盖请求期间到达的新消息。
- 版图、好友或弹窗快速切换时，即使订阅在组件卸载后才建立，也必须立即释放；发送状态与好友资料加载状态相互独立。
- 服务端使用“发送者 + 频道 + 时间窗”的确定性行 ID 原子限制并发发送；多个同时请求不能绕过最近消息查询的频率限制。

### 返回与关闭层级

- 社交界面按 `公开名片 → 私聊 → 社交面板 → 游戏页面历史` 的顺序响应 `Esc`，不会一次退出多层。
- 游戏返回按钮只回到最近一个不同的游戏页面；没有历史目标时显示禁用态。
- 标题页按钮和返回按钮职责分离：前者离开本局，存在未保存进度时必须确认；后者只做页内导航。
- 弹窗的关闭按钮、点击遮罩和 `Esc` 必须得到一致结果，并保留明确的无障碍标签。

## 4. 权限与发布准入

- 好友和聊天写入继续经过 Social Gateway；浏览器不直接写权威表。
- 世界消息附带的执政国必须由 Social Gateway 根据有效控制租约核验，客户端不能冒用其他国家身份。
- 频道读取必须先验证 `world_memberships`。
- 玩家发现必须同时按 `worldId` 查询成员并排除本人；没有当前共享版图时前端不得调用全局发现接口。
- 新注册流程发布前至少验证：表单校验、OTP 发送态、错误态、已验证密码登录、移动端无横向溢出。
- 真实邮箱验证码由外部邮件投递，自动化测试只验证 Appwrite 请求和 UI 状态；不可在代码或 CI 中硬编码验证码。
- 完整认证与响应式社交界面当前生产基线约为 JS 1119 KiB、CSS 103.7 KiB，门禁分别保持在 1122 KiB 与 105 KiB；后续新增代码应先复用现有规则并清理重复声明。

## 5. 阶段状态

- `RELEASED`：账号/社交视觉、点击反馈、强制验证注册、玩家发现、公开名片、一键好友申请、游戏内未读入口、版图频道、好友实时私聊、受限图片和消息竞态防护。
- `NEXT`：聊天屏蔽/举报、消息保留策略、在线状态与媒体生命周期产品评审。
- `BOUNDARY`：聊天和好友始终不得直接改变世界状态；外交与政策结果只由共享世界权威命令和 Resolver 结算。
