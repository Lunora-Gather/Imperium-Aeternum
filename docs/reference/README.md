# 规则与架构参考

本目录保存仍有设计价值的规则、公式、数据表、架构决策和 UI 方案。它们解释“为什么这样设计”，但当前运行事实仍以代码、测试和 `docs/maintenance/` 为准。

- `01-design-bible.md`：产品与玩法设计原则。
- `02-system-rules.md`、`03-data-tables.md`、`formulas.md`：规则与数值参考。
- `04-architecture.md`、`decisions.md`：架构演进和长期决策。
- `09-lever-*`：治理杠杆的历史交互与视觉方案。

这些资料可能尚未全部落地；实现新玩法前应先核对当前类型、引擎和数据定义。
